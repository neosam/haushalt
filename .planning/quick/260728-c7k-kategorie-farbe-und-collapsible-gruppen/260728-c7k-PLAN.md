# Quick Task 260728-c7k

## Ausgangslage

`TaskCategory` hat ein `color`-Feld, das im `CategoryModal` gesetzt und gespeichert wird.
Es kommt aber nie in der Task-Liste an: `shared::Task` transportiert nur `category_name`.
Der Kategorie-Header in `GroupedTaskList` nutzt darum fest `var(--text-muted)` auf
`var(--bg-secondary)` — die angezeigte Farbe hat nichts mit der eingestellten zu tun.

`GroupedTaskList` wird von `pages/household.rs` und `pages/dashboard.rs` verwendet,
Änderungen dort wirken also in beiden Ansichten.

## Entscheidungen (vom User bestätigt)

1. Farbdarstellung: **dezent** — farbiger Balken links am Kategorie-Header,
   Hintergrund bleibt wie bisher. Grund: funktioniert auch bei knalligen Farben und im Dark Mode.
2. Collapse-Zustand: **nur pro Seitenaufruf**, kein localStorage.
3. Defaults: Kategorien aufgeklappt, Tage ausser heute zugeklappt.
   Die Gruppe "Sonstige"/ohne Kategorie ist ebenfalls klappbar.

## Tasks

### Task 1 — Kategorie-Farbe vom Backend bis ins Frontend durchreichen

**files:** shared/src/types.rs, backend/src/models/task.rs, backend/src/services/tasks.rs,
backend/src/services/scheduler.rs, backend/src/handlers/tasks.rs, backend/src/test_utils.rs,
frontend/src/components/task_modal.rs, frontend/src/components/task_form_model.rs,
frontend/src/pages/tasks.rs, frontend/src/components/task_card.rs

**action:**
- `shared::Task` bekommt `category_color: Option<String>` direkt hinter `category_name`.
- `TaskRowWithCategory` bekommt `category_color: Option<String>`, `to_shared` kopiert es.
  `TaskRow::to_shared` setzt `None` (kein JOIN).
- Alle fünf `SELECT t.*, tc.name as category_name` in `services/tasks.rs` um
  `, tc.color as category_color` ergänzen.
- Alle übrigen `Task { .. }`-Literale um `category_color: None` ergänzen.

**verify:** `cargo check --workspace` ist warnungsfrei.
**done:** Ein Task mit Kategorie liefert über `list_tasks` die Farbe der Kategorie.

### Task 2 — Kategorie-Gruppe mit Farbe und Collapse

**files:** frontend/src/components/task_card.rs

**action:**
- `TaskWithHousehold::category_color()` als Getter ergänzen.
- `group_tasks_by_category` gibt `Vec<CategoryGroup>` zurück
  (`struct CategoryGroup { name, color, tasks }`), Farbe aus dem ersten Task
  der Gruppe, der eine hat. Sortierung/Verhalten sonst unverändert.
- Kategorie-Header: `border-left: 4px solid {color}` mit Fallback `var(--border-color)`,
  klickbar mit Chevron, `aria-expanded`. Inhalt wird per `style:display` ein-/ausgeblendet
  (nicht per `Show`, weil die Task-Views einmalig aus bewegten Daten gebaut werden).
- Default aufgeklappt.

**verify:** Tests für `group_tasks_by_category` (Farbe uebernommen, Fallback bei None).
**done:** Kategorie-Header zeigt die konfigurierte Farbe und klappt zu/auf.

### Task 3 — Tages-Gruppen ausser heute klappbar, default zu

**files:** frontend/src/components/task_card.rs

**action:**
- `DueDateGroup::is_collapsible()` → `!matches!(self, Today)`.
- `DueDateGroup::default_expanded()` → `matches!(self, Today)`.
- Header der Tages-Gruppe bekommt Chevron + Klick-Toggle, wenn `is_collapsible()`.
  "Heute" bleibt unverändert ohne Toggle.
- Gruppeninhalt per `style:display` ein-/ausgeblendet.

**verify:** Tests für `is_collapsible`/`default_expanded` über alle Varianten.
**done:** Beim Laden sind nur die heutigen Tasks sichtbar, andere Tage aufklappbar.
