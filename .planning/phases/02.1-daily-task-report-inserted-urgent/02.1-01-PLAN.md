<objective>
Close every Wave 0 harness and build gap that blocks the rest of Phase 2.1. Today the shared
backend test harness cannot support a single report-service test, and the frontend cannot
compile clipboard code.

Purpose: `backend/src/test_utils.rs::create_test_schema()` has no `missed_task_penalties` table
at all, and its `household_settings` table has 7 columns where `HouseholdSettingsRow` needs 22 —
so `household_settings::get_or_create_settings()` (which the report needs for D-04/D-12 timezone
resolution and the D-14 vacation check) fails against it. Two further gaps found while planning
and **not** listed in RESEARCH.md are closed here too (see Task 1). Separately, the root
`Cargo.toml` `web-sys` feature list has neither `Clipboard` nor `Navigator`, so D-26's copy
button cannot compile.

Output: a test harness that supports report-service tests, a `missed_task_penalties` fixture
helper, harness smoke tests, and the two `web-sys` feature flags.
</objective>
