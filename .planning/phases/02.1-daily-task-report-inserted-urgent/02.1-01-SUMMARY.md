## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Extended `TestTaskBuilder` with `with_suggestion()`**
- **Found during:** Task 2 (writing `test_task_with_approved_suggestion_insertable`)
- **Issue:** The plan's `<behavior>` for this test says to build the task "via the existing task builder," but `TestTaskBuilder` had no `suggestion` field, no `with_suggestion()` method, and its `INSERT` never wrote the `suggestion` column at all (it was always implicitly `NULL`) — the test as specified could not compile.
- **Fix:** Added `suggestion: Option<SuggestionStatus>` to the builder struct, a `with_suggestion()` method matching the existing `with_*()` style, added `suggestion` to the `INSERT` column list/binds, and changed the returned `Task`'s `suggestion` field from hardcoded `None` to `self.suggestion` (a no-op for every pre-existing call site, since the default is still `None`).
- **Files modified:** `backend/src/test_utils.rs`
- **Verification:** `test_task_with_approved_suggestion_insertable` passes; full backend suite (219 tests) still passes with zero regressions to any pre-existing test that uses `create_test_task`.
- **Committed in:** `b154d696` (Task 2 commit)
