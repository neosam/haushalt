      pinned date (D-04/D-12).
   e. Map the result:
      - `Ok(report_text)` → `HttpResponse::Ok().json(ApiSuccess::new(DailyReportResponse { report_text }))` (D-17)
      - `Err(ReportError::NotAMember)` → the same 403 body as (c) — defense in depth (T-04-A)
      - `Err(ReportError::HouseholdNotFound)` → `HttpResponse::NotFound().json(ApiError { error: "not_found", message: "Household not found" })`

        `HttpResponse::InternalServerError().json(ApiError { error: "internal_error", message: "Failed to generate report" })` (T-04-B)
