Build the read-only report view: a new household tab, a page that renders the backend's plain-text
block verbatim, and a copy-to-clipboard button.

rendering (preformatted, verbatim) and the single action (copy — explicitly NOT Web Share), D-27
translates the chrome while D-01 keeps the report body English.

Output: `ReportPage` at `/households/:id/report`, `ApiClient::get_daily_report`,
`utils::clipboard::copy_to_clipboard`, the `HouseholdTab::Report` variant, and de/en strings.
</objective>
